2026-11-17, 실제 Electron Windows 창의 콘텐츠를 `webContents.capturePage()`로 캡처했다. 테스트용 텍스트·테두리 PNG이며 사용자 카드 삽화를 변경하거나 생성하지 않았다.

배율은 `--force-device-scale-factor=1/1.25/1.5`를 적용한 **앱별 Windows 네이티브 렌더링**이다. 창 콘텐츠 크기를 목표 물리 크기/배율로 설정했으며 정수 DIP 반올림이 포함된다. 호스트 디스플레이는 1920×1080, 운영체제 배율 100%였다. Windows 설정의 전역 배율·모니터 해상도를 직접 변경한 결과는 아니다. 실제 DIP와 버튼 좌표는 `docs/validation/p4-a-packaged.json`에 기록했다.

변경 전후 스크린샷은 동일한 테스트 이미지·80줄 설명을 사용한다. 테스트마다 격리된 DB를 생성하므로 카드·캐릭터 UUID는 서로 다르다. 전체 검수는 프로젝트 루트의 `P4_A_REVIEW.md`를 참고한다.
