# P4-B Windows 비교 화면

기존 0.5.0(P4-A) EXE와 최종 0.5.1(P4-B) EXE의 실제 Windows 콘텐츠 캡처다. 실제 등록 이미지 14장의 복사본을 사용했고 원본 이미지 파일은 수정하지 않았다. 검수 카드의 이름 앞 홀수/짝수 번호, 역할·주문 비용 등은 격리된 테스트 라이브러리의 검수용 메타데이터다. 실사용 카드 정의를 편집한 화면이 아니다.

손패 비교는 20장, 해상도·배율 비교는 200장 라이브러리다. 200장은 실제 이미지 14장 + 글자/테두리만 있는 임시 이미지 186장으로 구성했다. 실제 카드 가독성은 앞쪽 14장으로 확인했으며 200장의 실제 사용자 카드 검수라고 주장하지 않는다.

배율은 Windows Electron의 `--force-device-scale-factor=1/1.25/1.5`와 창 콘텐츠 크기 조절로 검증했다. 호스트 1920×1080/100%의 전역 설정은 변경하지 않았다. 실제 DIP와 미리보기·사용 버튼 치수는 `docs/validation/p4-b-packaged.json`에 있다.
