# DnD TCG-fy · P4-B 카드 탐색 (0.5.1)

P4-B는 약한 손패 중첩·호버 상승·선택 강조, 방향키 탐색, 모션 감소, 작은 화면의 미리보기 확대와 자원 표시 설정 보존을 추가했습니다. [P4-B 최종 검수 보고서](P4_B_REVIEW.md)에 실제 등록 카드의 가독성, 20/50/200장 성능과 Windows EXE 검증을 구분해 정리했습니다. 최종 사용자 승인 전까지 P5는 시작하지 않습니다.

P4-A에서 우측 카드 사용 영역을 고정하고 긴 설명을 독립 스크롤로 분리했습니다. 왼쪽 자원은 이름·현재량/최대량·잔여 표시를 우선 보여 주며 항목을 누르면 수정 기능이 펼쳐집니다. 휴식과 자원 Undo는 패널 하단에 유지됩니다. 카드·덱·비용·템플릿·휴지통 관리는 상단 **관리** 메뉴에서 엽니다. [승인된 P4-A 중간 검수 보고서](P4_A_REVIEW.md)도 보존했습니다.

## 손패 조작과 키보드

- 손패에서 휠·왼쪽 드래그로 가로 탐색합니다. 6px 이상 드래그하면 카드 클릭을 억제합니다. 카드가 많으면 작은 범위에서 중첩을 늘리며 선택 관리에서는 중첩을 해제합니다. 격자 보기와 원본 확대는 유지합니다.
- Tab으로 카드 목록에 진입한 뒤 **←/→**, **Home/End**로 포커스를 이동합니다. **Enter/Space**는 포커스한 카드를 선택합니다. 포커스 이동만으로 선택이나 자원량이 바뀌지 않습니다. Tab은 나머지 카드를 모두 거치지 않고 우측 사용 영역 등 다음 조작으로 이동합니다.
- **Ctrl+F**는 카드 검색으로 이동합니다. 입력 중이거나 관리 대화상자가 열려 있으면 전역 단축키가 개입하지 않습니다. **ESC**는 확대·대화상자를 먼저 닫고, 플레이 화면에서는 카드 선택을 닫습니다.
- 자원 소비는 우측 **사용 확정**에서만 수행합니다. 카드 선택용 Enter/Space가 자원을 소비하지 않습니다.
- **환경 설정 → 모션 줄이기** 또는 OS의 모션 감소 설정에서는 상승과 전환 효과를 없애고 선택 테두리를 유지합니다.
- 자원 그룹 접힘은 캐릭터별로 저장됩니다. 자원 행을 펼쳐 **우선 표시**를 누르면 해당 모듈과 그룹이 먼저 표시됩니다. 계산·비용·회복·사용 이력·Undo에는 영향을 주지 않습니다.

P1.1에서 새 카드의 활성 덱 자동 연결, 우측 미리보기 클릭 확대, 손패의 마우스 휠/왼쪽 드래그 탐색을 추가했습니다. 유형별 개수와 역할/유형 안내도 표시합니다. 상세 검수는 [P1.1 보고서](P11_TEST_REPORT.md)를 참고하세요.

D&D 행동 선택지를 TCG 손패로 살펴보는 Windows 오프라인 카드 보드입니다. 카드 라이브러리·필터에 범용 자원 관리와 사용 확정을 연결했습니다. 카드 선택·확대만으로는 자원이 바뀌지 않습니다. P3에서 2014 단일 클래스 프리셋, 주문/계약 슬롯, 업캐스팅·홈브루 다운캐스팅과 클래스 변경 Undo를 연결했습니다. P3.1에서는 **카드 사용 규칙**을 무소모·주문 슬롯·사용 횟수·포인트 자원으로 단순화했습니다. [P3.1 검수 보고서](P31_TEST_REPORT.md)와 [P3 보고서](P3_TEST_REPORT.md)에 검증 결과와 제한을 기록했습니다. [P2 보고서](P2_TEST_REPORT.md)도 보존했습니다.

선택 관리에서 여러 비용·자원·카드를 한 번에 정리할 수 있습니다. [일괄 편집 검수 보고서](P31_BULK_TEST_REPORT.md)와 [SQLite v5 보충 계약](DATA_SCHEMA_P31_BULK.md)을 참고하세요.

휴지통 이동·복원·영구 삭제와 잠금 파일 정리 재시도를 추가했습니다. [휴지통 검수 보고서](TRASH_TEST_REPORT.md)와 [SQLite v6 계약](DATA_SCHEMA_TRASH.md)을 참고하세요.

## 카드 삭제와 휴지통

- 상단 **관리 → 선택 관리**에서 카드를 골라 **선택 카드 휴지통으로 이동**을 누릅니다. 현재 필터에 보이는 카드만 전체 선택하며 확인 창에서 카드 수·이름·영향 덱/캐릭터를 확인합니다. 현재 덱에서 제거는 그 덱 연결만 바꿉니다.
- 이동 직후 **휴지통 이동 실행 취소**로 해당 묶음을 한 번에 복원합니다. 자원 소비 Undo와 별도입니다.
- 상단 **관리 → 라이브러리 관리 → 휴지통**에서 이미지/이름/삭제 일시/이전 소속 덱을 보고 개별·일괄 복원합니다. 이미지는 클릭해서 원본으로 확대할 수 있습니다. Esc는 확대창만 닫습니다.
- 복원은 기존 카드 ID·설정·이미지를 유지하며 원래 덱에 빠진 연결만 끝에 추가합니다. 새 덱 구성을 덮어쓰지 않으며 없어진 덱은 안내하고 건너뜁니다.
- 영구 삭제는 휴지통에서만 수행합니다. 개별 삭제도 별도 확인을 받고 여러 카드/비우기는 `영구 삭제` 문구를 입력해야 합니다. 복원/소비 Undo로 취소할 수 없습니다.
- 파일이 잠겼으면 카드 데이터 삭제 후 이미지 정리를 대기열에 보관합니다. **이미지 정리 재시도** 또는 앱 재시작 시 정리하며, 대기 이미지는 앱에서 조회/재연결하지 못합니다. 공유 이미지는 보존합니다.
- 자원 패널 **최근 작업 → 전체 카드 사용 기록**에서 영구 삭제 후에도 당시 이름·비용·차감량을 확인합니다. 기존 자원 상태와 소비 Undo는 유지합니다.
- 삭제 범위는 앱의 카드 데이터와 확인된 비공유 관리 이미지입니다. 외부 가져오기 원본·기존 별도 백업·소속을 알 수 없는 과거 미참조 파일은 보존합니다. 관련 과거 일괄 편집 기록은 카드 재생성을 막기 위해 복원 불가가 될 수 있으며 확인 창에서 안내합니다.

## 일괄 선택 관리

- 상단 **관리 → 선택 관리**에서 현재 필터에 보이는 카드만 전체 선택합니다. 필터·캐릭터·덱을 바꾸면 선택이 해제됩니다. 이미지 밖에 체크박스를 표시합니다.
- **선택 카드 일괄 작업**을 펼쳐 태그 추가/제거, 현재 덱에서 제거, 다른 캐릭터의 덱에 추가할 수 있습니다. 원본 카드와 이미지는 유지됩니다.
- 카드 사용 규칙 → 고급 설정 → **복수 자원·사용 방식 편집** → **비용 선택 관리**에서 비용/사용 방식 전체 선택·해제, 선택 삭제, 모든 비용 제거를 수행합니다. 미저장 변경을 먼저 저장하거나 취소하세요. 확실한 슬롯 대안은 자동 슬롯 방식 전환을 제안합니다.
- **자원 관리 → 자원 선택 관리**에서 여러 장착 자원을 연결 해제하거나 템플릿을 삭제합니다. 연결 해제는 해당 캐릭터에서 사용 중지하고, 템플릿 삭제는 새 장착 목록에서 숨기며 기존 연결은 유지합니다.
- 모든 일괄 변경은 개수·범위·영향 미리보기 후 확정합니다. 공통 카드 변경은 영향 캐릭터를 표시합니다.
- **관리 → 일괄 편집 복원**은 재시작 후에도 사용할 수 있습니다. 이후 편집과 충돌하면 복원하지 않습니다. 자원 사용 Undo는 왼쪽 자원 패널에 별도로 유지합니다.

## 앱 실행

`release/win-unpacked/DnD TCG-fy.exe`를 실행하세요. 이 폴더 전체가 필요합니다. Node.js나 개발 서버 없이 동작합니다.

이전 실행·테스트·스크린샷 결과: [P1 보고서](P1_TEST_REPORT.md). [P0 보고서](TEST_REPORT.md)와 기존 계약 문서도 보존했습니다.

## 카드 등록과 탐색

1. 상단 **관리 → 카드 등록**에서 이미지를 선택하거나, 이미지 파일을 보드에 드래그해 놓습니다. PNG/JPG/JPEG/WebP를 지원합니다.
2. 이름·유형·역할·행동을 지정합니다. 여러 장을 가져오면 이름은 개별 입력하고 나머지 속성은 공통 적용합니다. 저장 후 각 카드에서 따로 수정할 수 있습니다.
3. **고급 설정**에서 사거리·거리(ft)·태그·메모를 지정합니다. 주문 유형을 고르면 기본 주문 레벨 0~9를 바로 지정할 수 있습니다. 이 값으로 시전 슬롯을 검증하며 주문 효과·피해·회복량은 계산하지 않습니다.
4. 활성 덱이 있으면 새 카드는 그 덱에 자동 추가됩니다. 덱이 없으면 안내 후 라이브러리에만 등록됩니다. 카드 저장 후 손패 위 휠·왼쪽 드래그 또는 격자로 탐색합니다. 카드를 선택한 뒤 우측 이미지를 클릭하면 원본을 화면에 맞추거나 원본 크기로 읽을 수 있습니다. ESC는 확대창을 닫고, 다시 ESC를 누르면 선택을 해제합니다.
5. 카드를 선택한 뒤 **관리 → 정보 수정**에서 이름·속성·태그를 바꾸거나 이미지를 교체합니다. 카드 ID와 덱 연결, 기존 비용 정의는 유지됩니다.

한 번에 최대 100장, 파일당 32 MiB, 총 디코딩 4천만 픽셀까지 가져옵니다. 확장자뿐 아니라 실제 형식과 디코딩을 검사합니다. 여러 파일 중 잘못된 파일은 별도로 안내하고 정상 파일은 등록 폼에 넣습니다. 원본을 리사이즈하거나 덮어쓰지 않습니다. 탐색용 썸네일은 별도 캐시에 보관합니다.

이미지가 없는 카드도 이름을 입력해 저장할 수 있습니다. 이미지가 외부에서 누락되면 대체 안내를 표시하며 메타데이터와 편집 기능을 유지합니다.

**휴지통 이동**은 확인 후 라이브러리/모든 덱에서 숨깁니다. 원래 카드 데이터와 이미지·비용·덱 소속을 보존하고 휴지통에서 복원할 수 있습니다. 영구 삭제는 별도 확인 후 처리합니다.

## 검색·필터·태그

- 역할: 공격/치유/보호/강화/약화/유틸/소생/기타. 역할과 행동·태그는 다중 선택입니다.
- 추가 필터: 행동 경제, 유형, 사거리 종류, 공통 태그. 제목은 부분 검색하며 공백/대소문자/유니코드를 정규화합니다.
- 같은 분류 안은 **OR**, 분류 사이는 **AND**입니다. 예: `(공격 OR 치유) AND 보너스 행동 AND 원거리`.
- 필터는 카드 표시만 바꿉니다. 변경 즉시 화면에 반영하고 SQLite에 저장합니다. 재시작하면 검색어와 선택 조건을 복원합니다.
- **전체**는 역할 선택만 해제합니다. **필터 초기화**는 검색어와 모든 속성 필터를 해제합니다. 라이브러리/덱 범위와 캐릭터 선택은 유지합니다.
- 카드 편집의 태그 선택/해제는 그 카드만 바꿉니다. **태그 관리**의 공통 태그 이름 수정/삭제는 해당 태그를 쓰는 카드 모두에 적용하므로 연결 수와 영향 범위를 표시합니다. 태그 이름을 바꿔도 ID는 유지됩니다.

## 캐릭터별 덱

**관리 → 캐릭터·덱**에서 이름을 입력해 캐릭터와 기본 덱을 만들 수 있습니다. 상단에서 활성 캐릭터/덱을 고르고, 전체 라이브러리에서 카드를 선택해 **관리 → 활성 덱에 추가/빼기**를 누르세요. **활성 덱** 보기로 해당 덱만 펼칩니다. 여러 캐릭터가 같은 카드 정의를 공유하고 덱 구성은 독립적으로 유지됩니다.

추가 덱 생성도 지원합니다. 새 프로필은 2014 규칙/레벨 1로 저장합니다. 활성 캐릭터의 **캐릭터·덱 → 클래스·레벨 설정**에서 프리셋을 적용합니다. 캐릭터 이름 편집/삭제나 모든 능력치 편집은 확장하지 않았습니다.

## 자원 설정과 사용

1. 캐릭터 선택 → **관리 → 자원 관리 → 새 자원 만들기**에서 이름·단위·최대치·소유 범위와 회복 조건을 지정합니다. 템플릿만 저장하거나 현재 캐릭터에 바로 장착할 수 있습니다. 같은 템플릿을 다른 캐릭터에 장착해도 현재량은 독립적입니다.
2. 카드를 선택하고 **관리 → 카드 사용 규칙**에서 무소모/주문 슬롯/사용 횟수/포인트 자원 중 하나를 고릅니다. 횟수·포인트는 자원 이름과 한 번에 쓰는 양만 지정합니다. 여러 사용 방식과 복합 비용은 고급 설정에서 편집합니다. 여러 카드가 같은 자원을 공유하고 한 사용 방식에 여러 비용을 붙일 수 있습니다. **적용 대상**에서 모든 캐릭터 또는 이 캐릭터만을 선택할 수 있습니다. 자원 연결은 캐릭터별 정보입니다. 다른 캐릭터가 참조하는 공통 비용 수정에는 영향 확인이 필요합니다. 비용을 없애면 무소모 사용을 기록할 수 있습니다.
3. 오른쪽에서 예상 변경량을 확인한 뒤 **사용 확정**을 누릅니다. 하나라도 부족하면 전체 차감을 거부합니다. 부족한 카드도 펼쳐 읽을 수 있습니다. 별도 **예외 사용** 확인은 자원을 차감하지 않고 기록만 남깁니다.
4. 왼쪽 자원 항목을 클릭하면 +/−·수동 현재량 조정·회복 정보가 펼쳐집니다. 자원 그룹도 접고 펼칠 수 있습니다. 짧은/긴 휴식·새벽·수동 회복은 패널 하단에서 실행합니다. 현실 시간에 따른 자동 회복은 없습니다. 긴 휴식은 전용 규칙 우선, 없으면 짧은 휴식 규칙을 한 번 적용합니다.
5. **직전 자원 변경 실행 취소**는 카드 사용·회복·수동 변경을 역순으로 복원합니다. 다중 자원은 함께 복원하고 재시작 뒤에도 사용할 수 있습니다. 템플릿/장착/비용 등 일반 설정 변경은 이전 기록을 되돌리지 못하는 경계입니다. P3 클래스·레벨 변경은 별도 스냅샷으로 실행 취소할 수 있습니다.

장착한 템플릿은 복제해서 편집합니다. 캐릭터별 **설정** 변경은 다른 캐릭터에 적용되지 않고, 최대치 변경 시 이미 소비한 양을 보존합니다. 연결 해제된 자원을 쓰던 비용은 재연결 전까지 사용할 수 없습니다. 기존 이미지·카드 속성·필터에는 영향을 주지 않습니다.

레벨별 일반 자원 트랙은 고정 레벨 비용으로 계속 사용할 수 있습니다. 주문 비용에 연결하려는 사용자 슬롯 템플릿은 새 자원/복제 화면에서 **슬롯 종류**를 일반 주문 슬롯 또는 계약 마법으로 명시하세요. 기존 P2 슬롯 트랙을 시전 슬롯으로 추정 변경하지 않습니다.

## 클래스와 주문 시전

1. **캐릭터·덱 → 클래스·레벨 설정**에서 2014 클래스와 1~20레벨을 선택합니다. 바드/팔라딘은 필요한 매력을 입력합니다. **변경 미리보기 → 클래스 변경 확정**에서만 자원을 생성·갱신합니다.
2. 기존 홈브루 자원과 수동 최대치는 유지합니다. 사라지는 프리셋 자원은 기본적으로 현재 상태의 수동 자원으로 남기고, 연결 해제를 선택하면 별도 확인합니다. 같은 일반 슬롯 단계는 소비량 보존, 새 단계는 최대량, 계약 슬롯은 전체 소비 개수 이월 정책을 사용합니다. 프리셋 최대치로 돌아가려면 장착 자원 설정의 **프리셋 / 레벨 표의 최대치 따르기**를 선택하세요.
3. 주문 카드에 기본 레벨을 지정하고 **관리 → 카드 사용 규칙 → 주문 슬롯**에서 기본 주문 레벨과 일반/계약 슬롯 계열을 선택합니다. 클래스 프리셋 슬롯은 자동 연결됩니다. 다른 슬롯 자원은 **슬롯 자원 직접 선택**으로 이름을 고릅니다. 사용 가능한 단계가 여러 개일 때만 오른쪽에 슬롯 선택 메뉴가 표시됩니다. 하나만 남으면 그 레벨과 다른 단계의 소진 상태를 안내합니다. 기본 레벨 미만은 거부하며 선택한 단계의 슬롯 1개만 소비합니다.
4. 소마법(0레벨)의 슬롯 비용은 무소모이며 선택 메뉴가 없습니다. 별도의 포인트/횟수 비용을 추가하면 그 비용은 적용합니다. 신비의 비전은 해당 레벨의 별도 횟수 모듈에 고정 비용 1을 연결하세요.
5. **홈브루 예외 사용**에서 기본 주문 레벨 미만 시전을 명시 허용하고 최소/최대 레벨을 설정합니다. 슬롯 또는 고정/선택형 사용자 비용을 조합할 수 있습니다. 레벨마다 소모량이 다르면 사용 방식을 나누어 각 허용 범위와 비용을 지정합니다. 무소모 시전도 명시적으로 구성할 수 있습니다.
6. 과거 사용 기록에는 당시 비용/기본 주문 레벨/선택 슬롯이 남습니다. 공통 규칙을 수정해도 전용 재정의와 과거 기록은 바뀌지 않습니다. 고급 설정의 **공통 사용 규칙으로 복귀**는 해당 캐릭터의 재정의만 해제합니다.

4레벨 주문 한 장에는 슬롯 비용 하나만 저장합니다. 사용할 때 캐릭터의 4·5·6레벨 슬롯 등이 자동으로 선택지에 나타납니다. 소진된 단계는 선택할 수 없고 남아 있는 가장 낮은 단계를 제안합니다. 기본 규칙의 레벨별 비용을 여러 개 만들 필요가 없습니다.

고정 횟수/포인트에는 범위 입력이 없습니다. 사용할 때 포인트 양을 고르는 경우에만 **고급 설정 → 사용할 때 포인트 양을 고르기**에서 최소·최대·간격을 지정합니다. 신비의 비전은 **사용 횟수**로 연결하며 계약 슬롯과 독립적입니다.

기존 여러 슬롯 레벨 비용·복수 사용 방식은 **기존 고급 설정**으로 유지합니다. 열거나 닫는 것만으로 바뀌지 않습니다. 기본 규칙으로 바꾸려면 새 유형 선택 → **변경 미리보기** → 전후 요약과 전환 확인 → **사용 규칙 저장**을 진행하세요. 복잡한 규칙을 계속 쓰려면 고급 설정 편집을 사용합니다.

자료는 공식 [SRD 5.1](https://media.wizards.com/2023/downloads/dnd/SRD_CC_v5.1.pdf)의 2014 규칙이며 2024 표를 혼용하지 않습니다. 클래스별 포함 자원·미지원 능력은 P3 보고서 표를 참고하세요. 소서러 포인트 전환·비전 회복의 슬롯 복구·주문 통달 등은 수동 설정/조정으로 관리합니다. 전투·피해·턴·상태이상 판정은 구현하지 않았습니다. [자료 고지](THIRD_PARTY_NOTICES.md)를 포함합니다.

## 개발 환경과 명령

Windows 10/11 x64, Node.js **24.x**, npm 11.x 이상을 사용합니다. 최초 설치와 패키징 도구 다운로드에만 인터넷이 필요합니다. Sharp의 Windows native 파일이 필요하므로 optional dependencies를 생략하지 마세요.

```powershell
cd C:\Users\HIKI\Desktop\DnD_TCG-FY\DnD_TCGfy_v1_0_Codex_Handoff
npm ci
npm run dev
```

이 환경처럼 Node만 있고 npm 명령이 없으면 프로젝트 내부 부트스트랩을 사용합니다. 전역 설치 없이 npm 11.6.2를 `.tools`에 받습니다.

```powershell
.\scripts\bootstrap-npm.ps1 ci --cache .tools/npm-cache
.\scripts\bootstrap-npm.ps1 run dev
```

아래 `npm ...`도 동일하게 `.\scripts\bootstrap-npm.ps1 ...`로 대체합니다.

```powershell
npm run lint
npm run typecheck
npm test
npm run build
npm start
npm run test:e2e
node scripts/e2e.mjs --dev --from-v5
npm run pack:win
$env:DND_TCG_EXECUTABLE = (Resolve-Path '.\release\win-unpacked\DnD TCG-fy.exe').Path
node scripts/e2e.mjs --from-v5
node scripts/p4-a-e2e.mjs
Remove-Item Env:DND_TCG_EXECUTABLE
node scripts/p4-a-e2e.mjs --dev
node scripts/prepare-p4-b-fixtures.mjs
node scripts/p4-b-e2e.mjs --dev
$env:DND_TCG_EXECUTABLE = (Resolve-Path '.\release\win-unpacked\DnD TCG-fy.exe').Path
node scripts/p4-b-e2e.mjs
Remove-Item Env:DND_TCG_EXECUTABLE
```

개발 모드는 Vite `127.0.0.1:5173`과 Electron을 함께 실행합니다. CSS는 개발 서버에서 생성한 임의 nonce로만 주입합니다. React/CSS 수정은 개발 화면에 반영되고 메인/preload 수정은 개발 명령 재실행이 필요합니다. 창을 닫으면 서버도 종료됩니다. `npm start`와 배포 exe는 빌드된 로컬 번들을 읽습니다.

E2E는 실제 Windows 창을 띄워 P0 v1 업그레이드 또는 --from-v5의 기존 P3.1 데이터 백업·v6 업그레이드, 테스트 이미지 20장 등록, 교체·필터·덱·드롭·태그 변경·누락 이미지·재시작·원본 해시와 P1.1 조작, P2 차감·회복·Undo·격리·중복 입력과 P3 클래스/시전/변경 Undo/공통·전용 비용을 검증합니다. 새 선택 관리의 비용/사용 방식 삭제·슬롯 전환·자원 연결 해제·템플릿 삭제·태그/덱 일괄 변경·재시작 후 복원도 검증합니다. 휴지통 삭제/복원/영구 삭제와 실제 Windows 파일 잠금·재시작·정리 재시도도 검증합니다. 텍스트/테두리만 있는 검수 이미지이며 사용자 삽화를 생성하지 않습니다. 모든 DB/이미지는 실행별 `artifacts/p1-e2e-*/user-data`에 격리합니다. 실제 사용자 데이터에는 접근하지 않습니다.

```powershell
npm run dist:win
```

`prepare-p4-b-fixtures.mjs`는 원본 DB·WAL의 크기/수정 시각이 복사 중 유지되는지 확인하고 검수 폴더에 읽기 복사한 후, Python 3의 내장 SQLite 읽기 전용 URI로 복사본만 조회합니다. Python은 이 선택적 검수 도우미에만 필요하며 앱 실행·빌드에는 필요하지 않습니다. 기본 `%APPDATA%\DnD TCG-fy`의 활성 카드 이미지를 `artifacts/p4-b-input`에 복사합니다. 다른 데이터 경로는 첫 인수로 지정할 수 있습니다. P4-B E2E는 이 복사본과 별도 텍스트 테스트 이미지만 격리된 라이브러리에 등록합니다. 실제 사용자 DB에는 쓰지 않습니다. 개발 모드 테스트는 Vite 포트를 사용하므로 동시에 두 개를 실행하지 마세요.

NSIS 예상 산출물은 `release/DnD-TCG-fy-Setup-0.5.1-x64.exe`입니다. P4-B에서는 폴더 배포 EXE를 빌드·실행했습니다. NSIS 설치·제거·업그레이드는 P5에서 검수합니다. 코드 서명은 없습니다.

## 데이터 위치와 호환성

배포 기본 경로는 `%APPDATA%\DnD TCG-fy`, 개발 기본 경로는 `%APPDATA%\DnD TCG-fy Development`입니다. P0와 같습니다.

```text
userData/
  data/app.sqlite3                     # SQLite v6, 도메인 데이터/필터/설정
  assets/<uuid>.png|jpg|webp            # 원본 바이트 복사본
  cache/thumbnails/<asset-id-hash>.webp # 재생성 가능한 탐색 캐시
  backups/before-v5-to-v6-<uuid>.sqlite3
  chromium/                            # 로컬 Electron 세션
```

v6보다 오래된 DB는 마이그레이션 전 일관성 백업을 만들고 트랜잭션으로 v6를 적용합니다. v6는 휴지통·이미지 정리 데이터를 추가하며 기존 카드/자원 행을 초기화하지 않습니다. 기존 archived 카드도 휴지통에서 확인하고 복원할 수 있습니다. 기존 카드 ID/태그 ID/캐릭터/덱/비용/자원/기록 및 P0 환경 설정을 유지합니다. 잘못된 새 입력과 지원하지 않는 미래 버전 DB를 거부하며 자동 리셋하지 않습니다. 잘못된 저장 카드 행은 경고하고 원본 행을 보존합니다.

P4-B도 SQLite v6입니다. 자원 표시 설정은 기존 `settings` 테이블의 별도 `resource_display` 키에 저장합니다. 이전 `preferences`의 세 필드는 그대로 유지하므로 P4-A도 읽을 수 있습니다. [P4-B 표시 설정 계약](DATA_SCHEMA_P4.md)을 참고하세요.

원본 파일은 외부 경로와 분리된 복사본이므로 외부 원본을 옮겨도 앱에 가져온 이미지는 유지됩니다. 교체 전 이미지와 취소된 가져오기의 미참조 복사본도 자동 삭제하지 않습니다. 영구 삭제에서 출처를 추적할 수 있는 비공유 이미지만 정리하며, 과거 미참조 자산 전체 정리 및 ZIP 백업/복원 정책은 P5에서 다룹니다. 실행 중 DB만 복사하면 WAL의 최근 변경을 빠뜨릴 수 있으므로 수동 백업은 앱을 완전히 종료한 상태에서 userData 전체를 보존하세요.

`DND_TCG_TEST_USER_DATA`는 E2E가 지정하는 절대 경로입니다. 일반 사용에서는 설정하지 마세요. 새 v6 DB는 0.4.2 이하 앱으로 다운그레이드해 열 수 없습니다. 이전 앱은 미래 버전으로 거부하며 데이터를 초기화하지 않습니다.

렌더러는 Node/파일/DB를 직접 읽지 못합니다. preload의 용도별 함수만 호출하고 메인이 입력과 프레임을 검증합니다. 이미지도 asset ID로 지정한 로컬 프로토콜로만 읽습니다. 경로 순회/네트워크 경로/포맷 위장/손상/크기 초과를 검사하며 외부 연결·새 창·권한 요청을 차단합니다.

## 코드와 다음 단계

- `electron/library-store.ts`, `assets.ts`: 카드/태그/덱 트랜잭션 및 원본·썸네일 관리.
- `electron/main.ts`, `preload.ts`, `security.ts`: IPC와 로컬 전용 프로토콜.
- `src/components/`: 등록 폼, 필터, 태그/덱 관리, 원본 확대.
- `src/shared/`: 런타임 계약, 순수 필터 및 자원 계산 함수.
