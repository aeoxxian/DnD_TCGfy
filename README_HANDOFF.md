# DnD TCG-fy Codex 인계 패키지

구성:
- `SPEC.md`: 제품 목적, 기능, 비기능, 인수 조건의 기준 문서.
- `DATA_SCHEMA.md`: 카드/자원/캐릭터/이벤트 타입 및 불변 조건.
- `IMPLEMENTATION_PLAN.md`: P0~P5 개발 단계와 검수 방법.
- `AGENTS.md`: Codex 작업 지침. 프로젝트 최상위에 그대로 유지 권장.

## Codex 시작 방법

1. ZIP을 원하는 Windows 개발 폴더에 압축 해제한다.
2. 해당 폴더를 Codex 프로젝트/작업 디렉터리로 연다.
3. 다음 프롬프트를 그대로 입력한다.

> `AGENTS.md`, `SPEC.md`, `DATA_SCHEMA.md`, `IMPLEMENTATION_PLAN.md`를 전부 읽고 충돌이나 불명확한 점을 문서화한 뒤 P0부터 구현하라. Windows 10/11 x64 오프라인 Electron 앱을 목표로 한다. 핵심 기능만 구현하고 규칙 판정 자동화는 추가하지 말 것. 매 단계마다 테스트와 실행법을 보고하고, P0 완료 검증 후 P1으로 진행하라.

## 초기 사용자 준비물

실제 카드 PNG 3~10장을 P1 테스트 때 전달하면 유용하다. 카드 이미지를 받지 못했을 때는 임시 플레이스홀더로 구현 가능하다. 예시 캐릭터는 워락 11레벨, 클레릭 8레벨, 홈브루 포인트형 자원 캐릭터를 사용한다.

## 참고

본 압축물은 **개발 명세 및 작업 지침**이며 완성된 실행 프로그램은 아니다. 모든 기능을 구현한 것으로 표현하지 말 것.
